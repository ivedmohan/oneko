## macOS

Open the dmg, drag Oneko to Applications. The app isn't notarized, so the first time **right-click, then Open**.

## Windows

Run the exe. SmartScreen will warn because it isn't signed: click *More info*, then *Run anyway*.
If the cat shows up and chases your cursor, let me know and this note goes away.

## Using it

Click the cat in the menu bar / system tray for Pause (hide), Character (neko, tora, dog, sakura, tomoyo) and Quit.
